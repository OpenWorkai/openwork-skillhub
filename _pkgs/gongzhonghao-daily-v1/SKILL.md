# 公众号日更生产 v1

## 概述

## 爆款内容策略（2026-07-25 起执行）

以下 6 条策略基于 Myking 实战总结（17 万+ 阅读验证），每日写稿和发布前必须逐条对照：

### 1. 短标题优先
- **主标题 ≤14 个汉字**，砍掉一切不必要的修饰词和问号后缀
- 需要补充信息时用副标题（公众号摘要字段），不要堆在主标题里
- 好标题示例：「AI 的记忆有多长」「AI 考了多少分」「别被 AI 骗了」
- 差标题示例：「AI 能记住你说了什么吗？聊聊「上下文窗口」」（太长，算法不偏好）

### 2. 追微信指数
- **写稿前**：搜索微信指数（https://weixin.sogou.com 或微信指数小程序），查看选题关键词的热度趋势
- 如果某个相关关键词近期上升猛（如某个 AI 产品名、某个热点事件），将其融入标题或开头钩子
- 优先选有热度上升趋势的选题方向，容易吃到流量红利

### 3. 控制篇幅
- **正文目标 800-1200 字**（不含标题和图片引用）
- 深度长文/教程类可放宽到 1500 字，但必须在开头明确告知读者「这篇有点长但值得」
- 宁可砍掉一个例子也要控制总长——完读率直接影响推荐权重
- 每段不超过 3 行，手机一屏能看完 2-3 段

### 4. 提高赞转比
- 每篇文章至少命中以下 4 个要素中的 **2 个**：
  - **共鸣**：说出读者心里想说但说不出口的话
  - **情绪**：惊讶、感动、愤怒、好笑——有情绪才会转发
  - **干货**：读完能直接拿去用的操作或知识
  - **有趣**：比喻贴切、段子自然、读着不累
- 写完后自检：这篇文章读者为什么会转发？如果答不上来，重写钩子或加一个金句

### 5. 30 分钟黄金期
- 文章发布后 **30 分钟内**的转发数是进第一流量池的关键指标
- 比正常多 10% 的转发 → 大概率进第一流量池 → 流量滚雪球
- **交付确认时必须提醒 Myking**：发布后立刻转发到社群/朋友圈冲量
- 如果有多个社群，优先转发到活跃度最高的群

### 6. 爆款复用
- 记录每篇文章的数据（阅读/点赞/转发/完读率），存入 `爆款追踪.md`
- 以前爆过的标题句式、别的平台爆火的内容角度，大概率还会爆
- 每周回顾数据，找出高表现文章的共同特征，复用到下周选题

## 每日生产流程

### Step 1：确认当天选题 + 策略预检

查阅 `references/content_plan.md` 确认当天是第几天、标题和文章类型。

**策略预检（写稿前完成）：**
1. 查微信指数：搜索选题关键词，看是否有上升趋势的热词可蹭
2. 确定标题：主标题 ≤14 字，副标题放摘要
3. 确认篇幅目标：常规 800-1200 字，教程类 ≤1500 字
4. 确认赞转比策略：这篇文章靠哪 2 个要素驱动转发（共鸣/情绪/干货/有趣）

### Step 2：写稿件

文件路径：`稿件/DayN-标题.md`

稿件结构（固定五段式）：
1. 开头钩子（生活场景/问题引入，2-3 句）—— 可蹭热词
2. 核心讲解（1 个概念 + 1 个比喻，≤300 字）
3. 实际例子（普通人能复制的操作，3-5 条）
4. 一句话总结（引用块格式）—— 金句，便于转发
5. 互动引导（留言话题 + 下期预告）

语气要求：
- 说人话，不用术语堆砌
- 像跟朋友聊天，不端着
- 每段不超过 3 行，适合手机阅读
- **正文字数控制在 800-1200 字**，写完检查总字数

### Step 3：生成封面图

用 `scripts/generate_cover.py` 脚本，基于 `cover_template.jpg` 母版生成：
- 用渐变色覆盖原标题区域
- 写入当天标题和副标题
- 输出 `cover_dayN.jpg`（1920×814，2.35:1）

使用方法：
```bash
python3 scripts/generate_cover.py "标题" "副标题" "输出路径"
```

### Step 4：生成 2 张内文插图

用 PIL 绘制，风格与封面统一：
- 尺寸：1200×800
- 背景：暖紫灰渐变 `#F7F2F5` → `#EBE4ED`
- 主色：紫色系 `#7B6B8D` / `#B0A1C3` / `#D2C8DC`
- 文字：深灰 `#2D3E4F`
- 圆角卡片 + 扁平图标 + 柔和阴影

插图内容根据文章段落选择关键概念，例如：
- 对比图（A vs B）
- 场景图（手机/生活中的应用）
- 流程图（步骤拆解）
- 概念图（比喻可视化）

输出路径：`images/dayN_illustration_01.png` 和 `images/dayN_illustration_02.png`

### Step 5：在稿件中插入图片引用

在 MD 稿件中按以下位置插入图片引用：

```markdown
# 让我们来聊AI · Day N

![Day N 封面](../cover_dayN.jpg)

## 标题

正文开头...

（核心讲解段落后插入插图 1）
![插图说明](../images/dayN_illustration_01.png)

（应用场景段落后插入插图 2）
![插图说明](../images/dayN_illustration_02.png)
```

封面图固定在标题下方第一行，2 张插图分别插入到对应段落之后。

### Step 6：转换为公众号 HTML

公众号编辑器不支持直接粘贴 MD 图片引用，需转换为带 base64 内嵌图片的 HTML 文件（用于邮件备用）。

使用方法：
```bash
python3 md_to_wechat_html.py "稿件/DayN-标题.md" "稿件/DayN-标题.html"
```

脚本功能：
- 将 MD 转为 WeChat 友好的 HTML（内联 CSS 样式）
- 所有图片转为 base64 data URI 内嵌（包括封面和插图）
- 排版适配公众号编辑器宽度（677px）
- 输出 HTML 文件，浏览器打开 → Ctrl+A 全选 → Ctrl+C → 粘贴到公众号编辑器

### Step 7：推送稿件到公众号草稿箱（主推，走 TX-2 中转）

通过 TX-2 服务器（175.178.38.146 固定 IP）中转调用微信 API，把当天文章写到公众号后台草稿箱，省去复制 HTML 的麻烦。

使用方法：
```bash
python3 publish_to_wechat_draft.py "稿件/DayN-标题.md" <day_number>
```

架构：
- 本地脚本解析 MD、编码图片为 base64、POST 到 TX-2
- TX-2 上的 `wechat_draft_proxy` 服务（systemd 守护）收到请求后执行：取 token → 上传封面 → 上传插图 → draft/add
- 微信 IP 白名单只需加 `175.178.38.146` 一次，永久生效

脚本功能：
- 读取 MD 文件，提取标题、摘要、封面和插图引用
- 封面和插图 base64 编码后随 JSON POST 到 TX-2
- TX-2 上传封面到 `material/add_material` 获取 `thumb_media_id`
- TX-2 上传 2 张插图到 `media/uploadimg` 获取微信图片 URL
- TX-2 调用 `cgi-bin/draft/add` 创建草稿，返回 `media_id`
- 成功后 Myking 只需在公众号后台草稿箱点击「发布」并设置定时群发

注意事项：
- ✅ 微信 IP 白名单已添加 `175.178.38.146`（TX-2 固定 IP，加一次永久生效，2026-07-11 验证通过）
- 该账号为未认证订阅号，`freepublish/submit` 接口报 48001，因此只能写到草稿箱，无法全自动发布
- TX-2 服务路径：`/home/ubuntu/wechat_proxy/server.py`，nginx 反代 `http://175.178.38.146/wechat/*`
- 若 token 获取失败报 40164，检查 TX-2 服务状态：`ssh -i ~/.ssh/Little_Boy.pem ubuntu@175.178.38.146 "sudo systemctl status wechat-proxy"`

### Step 8：发送 HTML 到邮箱（备用）

若草稿箱推送失败（如 IP 白名单问题），将生成的 HTML 文件作为备用方案发送到 Myking 的邮箱 893944505@qq.com。

使用方法：
```bash
python3 send_html_email.py "稿件/DayN-标题.html" <day_number> "<文章标题>"
```

脚本功能：
- 读取 HTML 文件，base64 编码为附件
- 通过 QQ Mail API 发送邮件（自动处理两步确认）
- 收件人：893944505@qq.com
- 邮件标题格式：【让我们来聊AI】Day N - 文章标题

注：ima 知识库（锦大少的知识库，ID: 001a92b739c049e8）仅支持读取，写入通过乐享知识库完成。
